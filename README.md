# Odontologia Integrada · Goiânia

Landing page estática para a clínica Odontologia Integrada.

## Preview local

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor HTTP local.

## Publicação

O workflow em `.github/workflows/pages.yml` publica a página no GitHub Pages quando há push na branch `deploy`. Alterações seguem pela branch `homolog` e entram em `deploy` após aprovação do pull request.

As imagens continuam hospedadas no site original da clínica.
